# Lamia Fashion House — Version 1 Working Package

বাংলাদেশি বাজারের জন্য Luxury Premium + South Asian Boutique ফ্যাশন স্টোরের প্রাথমিক ফ্রন্টএন্ড ও Admin Demo।

## ফাইল
- `index.html` — দোকানের হোমপেজ ও পণ্য ব্রাউজিং ডেমো
- `styles.css` — স্টাইল
- `app.js` — কার্ট, পণ্য ও ডেমো চেকআউটের আচরণ
- `admin.html` — ব্রাউজার-ভিত্তিক Admin Panel Demo
- `assets/design-reference.png` — ব্যবহারকারীর অনুমোদিত হোমপেজ ডিজাইনের রেফারেন্স ছবি

## পরীক্ষা
1. ZIP Extract করুন।
2. `index.html` ব্রাউজারে খুলুন।
3. একই ফোল্ডারের `admin.html` খুলে Admin Demo পরীক্ষা করুন।
4. ডেমো পাসওয়ার্ড: `1234` (শুধু স্থানীয় পরীক্ষা; নিরাপদ নয়)।

## গুরুত্বপূর্ণ
এই সংস্করণটি এখনও লাইভ ব্যবসায়িক সিস্টেম নয়। Admin সেটিংস ও ডেমো অর্ডার একই ব্রাউজারের Local Storage-এ থাকে। ছবির রেফারেন্সটি ডিজাইন লক্ষ্য; বর্তমান HTML/CSS-কে সেটির সঙ্গে আরও মিলিয়ে নিতে হবে। নিরাপদ লগইন, অনলাইন ডেটাবেস/ইমেজ স্টোরেজ, অনলাইন ব্যাকআপ, AI, পেমেন্ট ও কুরিয়ার ইন্টিগ্রেশন এখনো যুক্ত নয়। Public launch-এর আগে এগুলো বাস্তব ব্যাকএন্ডে তৈরি ও পরীক্ষা করতে হবে।
